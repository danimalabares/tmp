# Jardim exercise notes

Standalone notes from the exercise sessions in Salvador, with the sheaf
primer in Appendix A. This version expands the intermediate steps in the
section/quotient construction, linkage, the line and conic calculation,
and the Ext criteria.

Build with a standard TeX Live installation and `latexmk`:

```sh
cd jardim-exercises
latexmk -pdf -outdir=build jardim-exercises.tex
```

The PDF is `build/jardim-exercises.pdf`. Build files are not tracked.
The source is self-contained: no external preamble, bibliography file,
or image files are needed.
